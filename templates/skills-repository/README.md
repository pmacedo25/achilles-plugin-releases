# Meu catálogo de skills

Estrutura inicial para um repositório pessoal compatível com o Achilles.

1. Renomeie `example-skill` e ajuste o `SKILL.md`.
2. Crie skills adicionais dentro de `agent`, `plan`, `testing` ou `infra`.
3. Personalize `system-prompts/project-governance.md`.
4. Publique no GitHub e configure `owner/repositorio` em **Settings → Skills**.

Não inclua tokens, senhas ou dados privados nos arquivos versionados.
